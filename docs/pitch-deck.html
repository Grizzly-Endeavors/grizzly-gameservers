02 / Why Generic AI Breaks the Math

Why You Can't Just Drop a Frontier Agent into the Container

Pointing a generalist coding agent at a game server burns expensive turns rediscovering game layouts from scratch on every incident.

Generic Frontier Agent (e.g. Claude Code in Container)

Relies on pretraining memory, guesses the wrong path or mod loader rule, fails, searches the filesystem, and tries again:

1. Guess from training data → 2. Edit fails → 3. Search filesystem → 4. Read logs → 5. Retry
  • 10 to 20 turns per fix: Burns thousands of frontier tokens discovering where Valheim, Palworld, or Fabric stores configs.
  • 35 to 60s+ latency: Players sit waiting while the generalist agent explores directories.
  • No SRE guardrail: Mutates live world state directly with no automatic snapshot or health-verified rollback.
What the Economics Actually Require

To run an autonomous operator on every $12/month server, you have to eliminate the discovery turns:

1. Know the game layout up front → 2. Snapshot → 3. Apply & Verify
  • Zero discovery tax: The harness already knows each game's config files, mod APIs, and startup checks.
  • 2 to 5 turns on an open model: When the harness supplies domain structure, a fast open model on Fireworks solves the ticket in seconds.
  • Sub-cent unit cost: Drops inference cost per incident below $0.001 so hosts can bundle it on every server.
The bottleneck isn't raw reasoning IQ. It's domain structure, memory, and safe execution at open-model speed. Measured in Our Ablation
