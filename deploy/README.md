# deploy — Helm chart (ADR-020 delivery contract)

`grizzly-platform`'s Flux `HelmRelease` for this app renders `./deploy` (see `kubernetes/apps/grizzly-gameservers/` over there). This is where the bot/agent workload, its ServiceAccount, and app-level wiring live.

`templates/deployment.yaml` is the bot/agent Deployment. `templates/service.yaml` is the ClusterIP Service fronting the bot's in-game agent endpoint (port `9360`, the `@Gary` reverse loop). `templates/externalsecrets.yaml` syncs the bot/agent credentials from OpenBao into namespace-local Secrets via the `openbao` `ClusterSecretStore` — toggle with `externalSecrets.enabled` in `values.yaml`. It renders seven ExternalSecrets: `discord-bot` and `ollama-api` (under `grizzly-platform/gameservers/{discord,ollama}`), `grizzly-gameservers-db`, `grizzly-gameservers-kv-cache` and `grizzly-gameservers-s3` (foundation-store grants under `grizzly-platform/stores/{grizzly-gameservers,kv-cache}`, for the Postgres registries, Gary's deferred-task queue and world backups), `grizzly-gameservers-ingame` (the shared in-game agent bearer token under `grizzly-platform/gameservers/ingame`), and `grizzly-gameservers-operator` (the operator harness token under `grizzly-platform/gameservers/operator`). The Deployment consumes those Secrets and never talks to OpenBao directly (the `game-servers` egress leash blocks `10.0.0.200:8200`).

The two bearer tokens are separate on purpose and degrade differently. The in-game one is mounted into every game pod in this namespace, so without it the trigger route still runs, protected by NetworkPolicy alone. The operator one reaches Gary's full admin tool surface and can pre-approve destructive actions, so without it the `/operator/*` routes are not mounted at all. Those routes are reachable only over `kubectl port-forward` to the ClusterIP Service — never a NodePort or Ingress.

Agones is packaged as a standalone gated `HelmRelease` rather than a Helm dependency of this chart (see [ADR-001](../docs/decisions/001-agones-packaging.md)); it and the `cluster/` guardrails + Kyverno carve-out are wired separately, not through this chart.
